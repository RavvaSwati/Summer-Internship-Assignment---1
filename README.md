# Summer Internship Assignment - 1

## Overview
This project contains solutions for multiple Python programming, data analysis, visualization, and web scraping tasks.

The assignment demonstrates:
- Python programming fundamentals
- File handling
- Functions and error handling
- Data cleaning and preprocessing
- Data visualization
- Web scraping
- Context-based data collection
- Data analysis and reporting

---

## Dataset Used

Digital Burnout and Productivity Analytics Dataset:

https://www.kaggle.com/datasets/aiexplorer77/digital-burnout-and-productivity-analytics

Note:
The dataset CSV file is not included in this repository due to file size/storage considerations.
Please download the dataset manually and place it inside the appropriate task folder before running the scripts.
